Paste your GitHub token for jigarkpat3/ar-badge. Only a token that can write to this repository can change anything.

How to make a token
  1. GitHub › your picture › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Name: “Badge admin”. Expiration: 90 days (or what you like).
  3. Repository access: Only select repositories › jigarkpat3/ar-badge.
  4. Permissions › Repository permissions › Contents: Read and write (Metadata: Read-only is added by itself).
  5. Generate, copy it, paste it here.
